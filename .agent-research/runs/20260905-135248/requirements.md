# Requirements

Source the current Pons stock-pair inventory and support as many assets as possible for:

1. Launching a Sinjoh token paired with a stock token.
2. Launching a raffle that rewards stock.

Prior accepted product rules remain in force: every canonical stock is a supported Sinjoh asset;
delivery may use already-denominated stock, an executable Pons route, or protocol inventory; and
an operation is gated only when neither market liquidity nor reserved inventory can cover it.
