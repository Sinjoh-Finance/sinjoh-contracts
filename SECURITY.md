# Security Policy

Do not disclose suspected vulnerabilities in public issues, discussions, or
pull requests. Report them privately to the repository owner through GitHub's
private vulnerability reporting once it is enabled. Until then, contact a
Sinjoh organization owner directly and include:

- the affected package and source revision;
- a minimal reproduction or proof of concept;
- the expected impact and required preconditions; and
- whether the issue affects a deployed address.

No source revision should be assumed safe for deployment solely because it is
present in this repository. Deployment tags and runtime hashes establish
provenance; they do not replace an independent security audit.
